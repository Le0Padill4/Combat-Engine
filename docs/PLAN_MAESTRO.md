# Plan maestro — Combat-Engine

## Objetivo y límite

Extender el juego C++ existente con un motor académico que cumpla la rúbrica CMP3002. `ArenaCore` fue una alternativa de diseño sobre matchmaking y no reemplaza este juego. La UI existente es secundaria.

## Fechas

- **24–25 nov:** cerrar operaciones, candidatos, escenarios, datos sintéticos y contratos.
- **25–27 nov:** implementar estructuras propias, motor de referencia y operaciones.
- **27–28 nov:** pruebas/invariantes y al menos 10.000 operaciones aleatorias comparadas.
- **28–29 nov:** benchmarks de dos operaciones, CSV, gráficos e informe.
- **30 nov, 23:59:** verificar ZIP, README y entrega CMP3002.
- **1 y 3 dic:** defensa individual conforme a asignación del curso.

## Criterios de salida

6–8 operaciones contables con candidatos razonables y escenarios de ventaja para cada uno; al menos tres familias; dos estructuras propias; costos compartidos, complejidades, casos borde, referencia lenta, comparación diferencial, dos benchmarks, cuatro tamaños, dos escenarios, CSV, gráficos y ZIP. No reportar mediciones antes de ejecutarlas.

## Decisión de equipo

El usuario autorizó un equipo de tres. La guía CMP3002 proporcionada dice equipos de dos; se debe conservar esa discrepancia en el informe y confirmar aceptación académica del trío. Las contribuciones y calificaciones no se presumen.
